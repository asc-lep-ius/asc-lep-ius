### Selected work

**[sophia](https://github.com/asc-lep-ius/sophia)** — Student toolkit for TU Wien.
Automated course registration against a live registration window, a lecture
knowledge base with PDF indexing, FSRS spaced repetition with confidence
calibration, and deadline discovery with workload forecasting. Hexagonal
architecture, async throughout, bilingual docs, 1530 tests.

**[tame-swarm](https://github.com/asc-lep-ius/tame-swarm)** — Bio-inspired
multi-scale competency architecture for LLMs. VCG auction routing (Mixture of
Bidders) and activation steering for cognitive homeostasis, grounded in Michael
Levin's TAME framework.

**[nomos](https://github.com/asc-lep-ius/nomos)** — Citizen issue tracker for
Austrian municipalities. Anonymous submission, a defined municipal processing
workflow, and full audit logging. FastAPI · SQLModel · HTMX · Jinja2.

**[horae](https://github.com/asc-lep-ius/horae)** — Natural-language calendar
capture. Speak or type an event, get a CalDAV entry. `dateparser` first for the
offline fast path, local Ollama as fallback.
